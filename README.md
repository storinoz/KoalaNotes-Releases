# KoalaNotes para Android

Anotações pessoais e tarefas organizadas em conjuntos, com widget para a tela inicial.

[Baixar a versão mais recente](https://github.com/storinoz/KoalaNotes-Releases/releases/latest)

Instale o APK sobre a versão existente para manter suas notas. Compatível com Android 8.0 ou mais recente.

A partir da versão 0.11.0, abra Configurações e toque em Buscar atualização. Quando houver uma nova versão, o aplicativo permite baixá-la e abrir a instalação do Android.

Este repositório distribui os APKs, as informações de atualização e os checksums do KoalaNotes.
